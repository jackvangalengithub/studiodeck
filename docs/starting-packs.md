# Studio starting packs

A studio starting pack gives each new project its own editable slides and copies of client reference documents. It works for a solo studio and a team. Only studio admins manage the library; every studio member can use it in projects they create or edit.

## Set up your studio pack

1. Open **Studio settings → Manage starting pack**.
2. Choose **Use example slides** for a welcome, process and contact slide, or **Add slide** to create your own.
3. Edit the text, choose the order, and leave **Include in new projects by default** checked for your usual content. Optional items remain available in the project wizard.
4. Choose **Add reference PDF** to upload your studio terms, process guide or other client-facing reference. These documents appear under **Project documents**, without becoming presentation slides.

The welcome and contact templates replace the text on the built-in slides. Text and image templates add custom slides. Image templates accept JPG, PNG or WebP. Each attachment can be up to 20 MB, with up to 40 active templates per studio.

Use these placeholders in slide titles and text:

| Placeholder | Filled from |
| --- | --- |
| `{{project_name}}` | Project name |
| `{{studio_name}}` | Studio name |
| `{{designer_name}}` | Designer creating or applying the copy |
| `{{designer_email}}` | Their email address |
| `{{client_names}}` | Client contacts already added to the project |
| `{{location}}` | Project location |

Missing information remains as a visible placeholder. Edit the copied slide when you know the details before sharing. Placeholders do not change text inside uploaded PDFs or images.

## Create a project

1. Choose **New project** and enter its name.
2. Expand **Studio starting pack** to include or exclude individual items. Uncheck everything for a blank start.
3. Continue to the file step. Upload project files or choose **Add files later**.
4. Edit the copied slides like any other project slide. Reference PDFs process in the background; wait for processing to finish before sharing.

Each project receives independent file copies. Editing one project does not change the studio pack or another project. A studio logo present when a pack is applied at project creation is copied into the project branding.

## Let clients use the reference documents

Clients open **Project documents** in the presentation header to download their attached documents. **Ask about documents** opens the project assistant. Answers use extracted text from the versions attached to that iteration and cite source filenames and pages. Project proposals and quotes can also supply evidence. When terms conflict, the AI is instructed to show the conflict and ask the designer to clarify, rather than assume precedence.

Documents need readable extracted text. Without an AI connection, the existing offline helper shows relevant excerpts and citations. Only upload reference documents intended for clients.

## Add a missing studio slide to an existing project

Saving a studio template creates a new library version for future projects. Existing projects keep their slides and documents unchanged.

1. In an editable project's **Presentation** tab, choose **Add slide**.
2. Open the **Add from studio template** tab, choose an available slide, and select **Add template slide**.
3. Edit the new copy like any other project slide.

Only missing slide templates are offered. Existing copies are not offered again, even when the studio template has changed. Welcome and contact templates are available only when the project has no custom text for that built-in slide. Reference PDFs are selected when creating a project.

For a locked presentation, create a new iteration before adding slides. Existing client links keep their shared iteration. Archiving a library item removes it from new-project choices and Add slide; existing copies remain available.
